Capítulo 38 — Indexado de archivos

Instalación de Gentoo · Sección opcional · Herramienta: mlocate

¿Para qué sirve este capítulo? Instalar una herramienta que crea un "catálogo" de todos los archivos del sistema, para poder buscarlos por nombre de forma casi instantánea, en vez de recorrer el disco completo cada vez.

38.1 El concepto: índice vs. búsqueda en vivo

Cuando buscas un archivo en Linux tienes dos caminos:

MétodoCómo funcionaVelocidad
find /Recorre el disco carpeta por carpeta en el momento de la búsquedaLento en discos grandes
locateConsulta una base de datos ya construida de antemanoCasi instantáneo

La base de datos se actualiza periódicamente (normalmente vía cron, que ya configuraste en el capítulo 37). Es el mismo comando locate que probablemente conoces de Debian/Ubuntu.

38.2 Instalación

RIESGO BAJO — Reversible
Para qué sirve: descarga e instala el paquete mlocate, que incluye el comando de búsqueda (locate) y el generador de la base de datos (updatedb).
root # emerge --ask sys-apps/mlocate

38.3 Cómo se usa

Construir/actualizar el índice

Para qué sirve: escanea todo el sistema de archivos y guarda la lista en la base de datos. Sin este paso, locate no encuentra nada nuevo.
# Ejecutar manualmente cuando lo necesites
root # updatedb

En un sistema normal no necesitas correrlo a mano: cron lo ejecuta automáticamente todos los días (revisa /etc/cron.daily/).

Buscar archivos

$ locate nombre_archivo

Devuelve todas las rutas que contienen ese texto, aunque no sea el nombre exacto.

38.4 Opciones más útiles de locate

OpciónQué hace
-iIgnora mayúsculas/minúsculas
-cSolo cuenta cuántos resultados hay, no los lista
-l NLimita la salida a N resultados
-eVerifica que el archivo aún exista en disco (más lento)
-rInterpreta el patrón como expresión regular
# Ejemplo: buscar archivos .conf sin importar mayúsculas, máximo 10 resultados
$ locate -i -l 10 .conf

38.5 Dónde se configura

El archivo de configuración es /etc/updatedb.conf. Ahí se ajusta:

  • PRUNE_PATHS — carpetas que no se deben indexar (ej. /tmp, /mnt, puntos de montaje temporales)
  • PRUNE_BIND_MOUNTS — si se ignoran los montajes tipo bind (normalmente "yes")
  • PRUNEFS — tipos de sistema de archivos a excluir (ej. nfs, tmpfs)
root # nano -w /etc/updatedb.conf
Nota de seguridad (información adicional, no está en el manual)

La base de datos de mlocate se genera respetando permisos: un usuario normal no puede ver rutas de archivos que no tiene permiso de leer. Aun así, si guardas datos sensibles fuera de tu carpeta personal, revisa PRUNE_PATHS para excluirlos del índice.

¿Y si no me interesa buscar archivos por terminal?

Este capítulo es opcional. Puedes saltarlo sin que afecte el resto de la instalación — no tiene relación con el arranque, el kernel ni el bootloader. El siguiente paso crítico sigue siendo GRUB (capítulo 44).
