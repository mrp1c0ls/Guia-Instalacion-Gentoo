Cap. 40 — Shell Completion (Bash)

Opcional Riesgo bajo

Autocompletado inteligente en bash: presionas Tab y el shell te sugiere comandos, opciones (--flags), rutas y hasta paquetes de Portage. Es pura comodidad — no toca el arranque, el kernel ni nada crítico del sistema.

¿Qué problema resuelve?

Por defecto, bash en Gentoo solo completa nombres de archivos y comandos básicos. No sabe, por ejemplo, qué opciones acepta emerge o systemctl. El paquete bash-completion le agrega a bash "diccionarios" de reglas por comando, para que el Tab sea mucho más útil.

¿Para qué sirve realmente, en la práctica?

Evita errores de tipeo en comandos largos (nombres de paquetes, flags de emerge, subcomandos de git, etc.) y ahorra tiempo al no tener que recordar la sintaxis exacta de cada herramienta. Es más notorio cuanto más usas la terminal a diario.

Instalación

root # emerge --ask app-shells/bash-completion
¿Qué instala este comando?

El paquete app-shells/bash-completion, que trae:

  • Un framework central que bash carga al iniciar sesión.
  • Scripts de completado individuales para cientos de comandos comunes (tar, git, ssh, rsync, etc.).
  • Reglas específicas para herramientas propias de Gentoo, como emerge — por ejemplo, escribir emerge --a y presionar Tab sugiere --ask, --autounmask, etc.

¿Dónde se configura y cómo se activa?

No requiere edición manual de archivos para funcionar de forma básica. El paquete se engancha automáticamente al iniciar una sesión de bash interactiva, a través de /etc/bash/bashrc (o /etc/profile.d/, según la versión). Basta con cerrar y volver a abrir la terminal (o hacer source /etc/bash/bashrc) después de instalarlo.

Nota: si estás dentro del entorno chroot haciendo la instalación, el autocompletado nuevo aplicará quzando arranques el sistema instalado y abras una sesión de bash normal ahí — no dentro del live environment.

Gestión fina con eselect

Una vez instalado el paquete, puedes activar o desactivar completions por comando individual usando el módulo bashcomp de eselect — la misma herramienta que ya usaste para eselect news o para elegir perfil.

ComandoQué hace
eselect bashcomp listMuestra todos los completions disponibles y cuáles están activos/inactivos.
eselect bashcomp enable <nombre>Activa el completion de un comando específico.
eselect bashcomp disable <nombre>Desactiva uno puntual (útil si genera lentitud o conflictos).
eselect bashcomp enable --globalActiva todos los completions disponibles de una vez.
 
# Ejemplo: ver qué completions hay disponibles
root # eselect bashcomp list

# Ejemplo: activar solo el de git
root # eselect bashcomp enable git
Analogía con NixOS: es parecido a poner programs.bash.enableCompletion = true; en tu configuration.nix — activa el mecanismo, pero aquí en Gentoo el paquete se emerge de forma explícita y luego puedes afinar comando por comando con eselect, en vez de una sola opción declarativa global.

Verificación rápida

Para confirmar que quedó activo, abre una terminal nueva y prueba:

$ emerge --
# Debería listar todas las opciones largas de emerge (--ask, --deep, --update, ...)

¿Es necesario para tu instalación?

No. Es completamente independiente de OpenRC, GRUB, dracut o cualquier paso crítico. Puedes instalarlo ahora o después del primer arranque sin ningún impacto en el resto del proceso.
