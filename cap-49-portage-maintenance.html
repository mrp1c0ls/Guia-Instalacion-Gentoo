1. El problema

Cada vez que emerge instala o actualiza un paquete, guarda una copia local del trabajo realizado:

Tipo de archivoUbicación por defectoVariable en make.conf
Tarballs de código fuente descargado/var/cache/distfilesDISTDIR
Paquetes binarios compilados (binpkgs)/var/cache/binhost/gentooPKGDIR

El detalle clave: cuando actualizas un paquete, Portage no borra la versión anterior descargada. Se queda ahí. Si nunca limpias, estos directorios crecen sin límite — se han reportado casos de varios gigabytes acumulados solo en DISTDIR tras meses de uso normal.

2. Para qué sirve conservarlos (y por qué limpiarlos igual)

✔ Ventaja de conservarlos

Si necesitas reinstalar o hacer downgrade de un paquete, ya tienes el archivo local — no hay que descargarlo ni recompilarlo de nuevo. También sirve como respaldo si algún día el mirror de Gentoo deja de tener disponible esa versión específica.

✘ Desventaja de no limpiar

Versiones antiguas que ya nadie va a volver a instalar simplemente ocupan espacio en disco de forma indefinida, sin ningún beneficio real.

Para qué sirve eclean Es la herramienta que resuelve ese balance: identifica automáticamente qué archivos ya no corresponden a ningún paquete instalado (o a ningún ebuild disponible, según el modo) y los elimina, dejando intactos los que sí podrías necesitar.

3. Instalar gentoolkit

gentoolkit es un paquete que agrupa varias utilidades de administración para sistemas Gentoo. eclean es una de ellas (junto con equery, eread, revdep-rebuild, entre otras).

root # emerge --ask app-portage/gentoolkit
  1. Portage resuelve las dependencias del paquete app-portage/gentoolkit.
  2. --ask muestra el plan de instalación y pide confirmación antes de proceder.
  3. Se compila (o se instala desde binpkg si aplica) y queda disponible en el sistema.
  4. A partir de aquí, los comandos eclean-dist y eclean-pkg están disponibles como atajos de eclean.

4. eclean-dist — limpiar tarballs de código fuente Seguro por defecto

Limpia archivos obsoletos dentro de DISTDIR (/var/cache/distfiles).

root # eclean-dist
Proceso paso a paso de qué hace este comando
  1. Escanea el árbol de ebuilds de Portage (y overlays, si tienes) para saber qué versiones de qué paquetes existen actualmente como ebuilds disponibles.
  2. Recorre DISTDIR comparando cada archivo contra esa lista.
  3. Por defecto (modo seguro), conserva cualquier tarball que aún corresponda a algún ebuild disponible en el repositorio — esté o no instalado ese paquete en tu sistema.
  4. Borra únicamente los tarballs que ya no corresponden a ningún ebuild existente (paquetes descontinuados o versiones eliminadas del árbol de Portage).
  5. Muestra un resumen del espacio liberado al terminar.
Nota sobre velocidad Este modo por defecto es el más lento de los tres disponibles, porque necesita revisar todo el árbol de Portage completo (incluyendo overlays) para decidir qué proteger.

5. eclean-pkg — limpiar paquetes binarios Útil sobre todo con binpkgs

Limpia archivos obsoletos dentro de PKGDIR (/var/cache/binhost/gentoo).

root # eclean-pkg

Funciona con la misma lógica que eclean-dist, pero sobre paquetes ya compilados en formato binario en vez de código fuente. Es especialmente relevante si usas la característica FEATURES="buildpkg" (que genera un binpkg cada vez que compilas algo) o si configuraste un host de binpkgs.

6. Modos de protección

eclean tiene tres niveles de "qué tan agresivo" es al limpiar. Se controlan principalmente con la opción -d / --deep:

Modo por defecto (seguro)

Protege todo lo que corresponda a cualquier ebuild disponible en el árbol de Portage, esté instalado o no. Ideal si quieres poder reinstalar cualquier cosa sin volver a descargar. Más lento y deja más archivos.

--deep / -d

Solo protege archivos que correspondan a paquetes instalados actualmente, en su versión exacta. Libera mucho más espacio, pero si desinstalaste algo por error tendrás que volver a descargarlo. Es el modo más rápido.

Un punto intermedio: combinar --deep con -n / --package-names protege todas las versiones de los paquetes instalados (no solo la versión exacta actual), en lugar de solo la última.

# Modo agresivo: solo conserva lo mínimo para reinstalar lo que ya tienes
root # eclean-dist --deep

# Modo intermedio: conserva todas las versiones de paquetes instalados
root # eclean-pkg --deep --package-names

7. Tabla de opciones disponibles

Opciones globales (aplican a ambos comandos)

OpciónQué hace
-p, --pretendSolo muestra qué se borraría, sin borrar nada. Siempre recomendable correrlo primero.
-i, --interactivePide confirmación antes de cada eliminación.
-d, --deepSolo conserva lo mínimo necesario para reinstalar los paquetes ya instalados.
-n, --package-namesCon --deep: protege todas las versiones instaladas, no solo la exacta actual.
-t, --time-limit=<tiempo>No borra archivos modificados recientemente (ej. 1y, 2w, 3d).
-e, --exclude-file=<ruta>Usa un archivo de exclusión personalizado (ver sección 8).
-q, --quietSalida mínima, solo errores.
-C, --nocolorDesactiva colores en la salida.

Opciones exclusivas de eclean-dist

OpciónQué hace
-s, --size-limit=<tamaño>No borra archivos más grandes que el tamaño indicado (ej. 50M).
-f, --fetch-restrictedCon --deep: protege archivos marcados como "fetch-restricted" (los que hay que descargar manualmente, no vía mirror).
--skip-vcsProtege fuentes de control de versiones (ebuilds "live") no instalados.

Opciones exclusivas de eclean-pkg

OpciónQué hace
--changed-depsBorra binpkgs cuyas dependencias del ebuild original ya cambiaron (quedaron desactualizados respecto al árbol actual).
-i, --ignore-failureIgnora el error si no logra localizar PKGDIR.
Flujo recomendado 1) Corre con --pretend para ver qué se borraría → 2) revisa la lista → 3) si todo se ve bien, vuelve a correr el comando sin --pretend. 
# Paso 1: revisar qué se limpiaría, sin tocar nada
root # eclean-dist --pretend

# Paso 2: ejecutar de verdad
root # eclean-dist

8. Archivos de exclusión

Si quieres proteger paquetes específicos de la limpieza (por ejemplo, porque sabes que vas a reinstalar algo pronto), puedes crear un archivo de exclusión:

ComandoArchivo de exclusión usado por defecto
eclean-dist/etc/eclean/distfiles.exclude
eclean-pkg/etc/eclean/packages.exclude

Formato del archivo (líneas de texto plano):

# Proteger toda una categoría
sys-apps

# Proteger un paquete específico (todas sus versiones)
app-shells/bash

# Excluir un paquete de una protección de categoría
!sys-apps/portage

# Proteger un archivo distfile específico por nombre
openoffice-i18n-3.0.tar.gz

# Proteger archivos que coincidan con una expresión regular
.*\.sig$

9. Extra: otras herramientas de gentoolkit

Ya que instalaste gentoolkit, vienen incluidas otras utilidades que valen la pena conocer para el mantenimiento continuo del sistema:

HerramientaPara qué sirve
equeryConsultar información de Portage: dependencias, metadatos y archivos instalados de un paquete.
ereadMostrar los mensajes "elog" que Portage guarda durante instalaciones (avisos, notas post-instalación de cada paquete).
revdep-rebuildDetecta binarios rotos por dependencias faltantes tras actualizaciones y los reconstruye.
quickpkgCrea un binpkg de un paquete ya instalado, sin recompilarlo.
Relación con otros comandos del handbook eclean limpia archivos descargados/compilados que ya no se usan. Es distinto de emerge --depclean (visto en capítulos anteriores), que desinstala paquetes completos que ya no son necesarios en el sistema. Ambos se complementan: primero --depclean para quitar paquetes sobrantes, luego eclean-dist / eclean-pkg para limpiar el caché de descargas.

Nota sobre OpenRC / systemd Este capítulo no tiene pasos diferenciados por sistema de init — eclean es una herramienta de Portage que funciona igual sin importar si el sistema usa OpenRC o systemd. No requiere ningún servicio corriendo ni configuración de arranque.
