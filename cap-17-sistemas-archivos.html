Capítulo 17 · Creación de sistemas de archivos

Manual de Gentoo AMD64 — resumen simplificado

Ya tienes las particiones creadas. Ahora toca darles formato: decidir cómo se van a organizar los datos dentro de cada una. Es como comprar un librero (la partición) y elegir cómo vas a acomodar los libros dentro (el sistema de archivos).

📂 Sistemas de archivos disponibles

Sistema¿Para qué sirve?
XFSRecomendado por Gentoo como opción moderna de uso general. Soporta reflinks y Copy-on-Write, ideal si compilas mucho software.
ext4Clásico y confiable, pero sin funciones modernas como reflinks.
VFAT (FAT32)Obligatorio para la partición EFI en sistemas UEFI. No soporta permisos de Linux.
btrfsSnapshots, autoreparación, compresión, RAID integrado. RAID 5/6 aún no es seguro.
F2FSPensado para memorias flash (USB, microSD).
NTFSSolo para interoperar con Windows, no como raíz de Gentoo.
ZFSEnfocado en integridad de datos y administración simple del almacenamiento.
¿Qué son los reflinks? (bonus)

Una copia de archivo casi instantánea que no ocupa espacio extra al crearse: el nuevo archivo apunta a los mismos datos que el original. Solo cuando modificas uno de los dos, el sistema copia (en ese momento) la parte que cambió — esto se llama Copy on Write. Es distinto a un hard link, que comparte los datos para siempre: el reflink se separa automáticamente en cuanto algo cambia, comportándose como una copia real pero con el ahorro de espacio de un enlace.

⚙️ Comandos para formatear

Para qué sirve: cada sistema de archivos tiene su propio comando mkfs.* que "instala" ese formato en la partición.
SistemaComando
XFSmkfs.xfs
ext4mkfs.ext4
VFATmkfs.vfat
btrfsmkfs.btrfs
F2FSmkfs.f2fs
NTFSmkfs.ntfs
ZFSzpool create ...
Cuidado: cualquier comando mkfs borra todos los datos existentes en esa partición. No hay marcha atrás.

Partición EFI Medio

Debe ser FAT32 obligatoriamente si usas UEFI:

root # mkfs.vfat -F 32 /dev/sda1

Partición raíz con XFS Alto

root # mkfs.xfs -c options=/usr/share/xfsprogs/mkfs/lts_6.18.conf /dev/sda3

ext4 en particiones pequeñas (<8 GiB) Bajo

Para qué sirve: la opción -T small cuadruplica el número de inodos disponibles (de 1 cada 16kB a 1 cada 4kB), útil si esa partición va a guardar muchos archivos pequeños.
root # mkfs.ext4 -T small /dev/<device>

💧 Activar el swap

El swap no lleva un sistema de archivos como tal: se inicializa con mkswap y se activa con swapon.

root # mkswap /dev/sda2
root # swapon /dev/sda2
Para qué sirve: esta activación manual solo es necesaria ahora, en el entorno live. Tras instalar el sistema y reiniciar, el swap se activa solo si está bien definido en /etc/fstab.
¿Qué es exactamente el swap? (bonus)

Es espacio en disco que el sistema usa como memoria RAM de respaldo cuando la RAM real se llena. Es más lento que la RAM, pero evita que el sistema se caiga por falta de memoria. También se usa para la hibernación (guardar el estado de la RAM en disco al apagar).

✅ Resumen rápido

  1. Elige el sistema de archivos según cada partición (XFS para raíz, FAT32 obligatorio para EFI).
  2. Formatea cada partición con su mkfs.* correspondiente.
  3. Si el ext4 va en una partición chica, usa -T small.
  4. Inicializa y activa el swap con mkswap y swapon.
