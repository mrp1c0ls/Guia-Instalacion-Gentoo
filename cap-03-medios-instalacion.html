Capítulo 3 — Medios de instalación de Gentoo

Elegir con qué imagen vas a arrancar el instalador, y qué es un stage file.

Para qué sirve este capítulo: antes de instalar Gentoo necesitas arrancar una computadora desde algún medio (USB, CD, etc). Aquí eliges qué tipo de imagen usar para eso.

3.1 — CD de instalación mínimo (Minimal Installation CD)

SIN RIESGO

Es una imagen pequeña y autosuficiente. Al arrancar, detecta el hardware automáticamente y carga los drivers necesarios. Todo se hace desde la terminal.

RequisitoMínimo 140 MB de RAM
InterfazSolo terminal (texto)
Nombre típicoinstall-amd64-minimal-<fecha>.iso

3.2 — Gentoo LiveGUI

SIN RIESGO

Versión más cómoda: trae un escritorio KDE completo, con navegador gráfico para leer el manual mientras instalas en otra ventana de terminal. También tiene mejor soporte WiFi (con applet de NetworkManager visual).

RequisitoMínimo 2 GB de RAM
InterfazEscritorio gráfico (KDE)
VentajaMejor soporte de drivers WiFi
¿Cuál elegir?

Si tu equipo es limitado en recursos o prefieres trabajar 100% en terminal, usa el Minimal CD. Si tienes suficiente RAM y quieres comodidad (navegador para leer el manual mientras instalas), usa el LiveGUI. Ambos instalan exactamente el mismo Gentoo — la diferencia es solo el entorno desde el que trabajas.

3.3 — ¿Qué son los "stage files"?

SIN RIESGO

Un stage file es un archivo comprimido que sirve como "semilla" del sistema: es el sistema base mínimo desde el cual se construye todo Gentoo. Se descarga desde releases/amd64/autobuilds/ en los mirrors oficiales.

Nota histórica: antes existían stages 1 y 2, pero quedaron obsoletos. Hoy solo se usa stage3.

Información adicional — ¿Qué combinaciones de stage3 existen?

Contenido relacionado, útil para decidir qué descargar más adelante

El stage3 se elige combinando dos decisiones independientes:

CategoríaOpción AOpción B
Sistema de inicio (init) OpenRC — nativo de Gentoo, basado en dependencias systemd — moderno, usado por la mayoría de distros
Arquitectura de librerías Multilib — 64 bits + compatibilidad 32 bits No-multilib — 64 bits puro
Recomendación para principiantes: OpenRC + multilib (o systemd + multilib si prefieres systemd). Evita no-multilib al empezar — migrar de ahí a multilib después es muy difícil.
¿Cuándo se configura el profile?

El stage3 ya trae un profile activado por defecto — no hay que hacer nada aquí. Más adelante, ya dentro del sistema (chroot) y con Portage sincronizado, se puede revisar o cambiar con:
