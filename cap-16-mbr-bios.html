Capítulo 16 — Particionando el disco con MBR para BIOS / Legacy Boot

Gentoo Handbook AMD64 · Resumen simplificado
Es la versión "clásica" del particionado, para equipos que arrancan en modo BIOS/legacy en vez de UEFI. Usa la tabla de particiones MBR/DOS en lugar de GPT. La lógica es la misma que en GPT (Cap. 15): una partición de arranque, una de swap y una raíz — solo cambia la herramienta interna que usa fdisk y que no existe una ESP.

¿Cuándo se usa MBR en vez de GPT?

Solo si tu placa madre es de antes de 2010 o no soporta UEFI, o si estás en un entorno de nube que aún depende de BIOS legacy (por ejemplo, algunas instancias de AWS). Fuera de esos casos, GPT es lo recomendado.

Limitaciones de MBR:
  • No puede direccionar discos de más de 2 TiB.
  • Máximo 4 particiones primarias (a menos que uses una extendida).
  • No tiene copia de respaldo de la tabla de particiones: si se daña, se pierde todo.

Esquema de particiones

ParticiónPunto de montajeSistema de archivosFunción
/dev/sda1/bootxfsArranque (reemplaza a la ESP de GPT)
/dev/sda2— swapMemoria de intercambio
/dev/sda3/xfsRaíz del sistema
Diferencia clave con GPT: aquí no existe la ESP (FAT32). En su lugar, /boot cumple ese papel y puede formatearse con cualquier sistema de archivos que tu bootloader soporte (por ejemplo XFS).

Pasos con fdisk

1. Abrir la herramienta sobre el discobajo riesgo
Para qué sirve: entra al modo interactivo de fdisk; todavía no modifica nada.
fdisk /dev/sda
2. Ver la tabla actualbajo riesgo
Para qué sirve: muestra qué particiones existen antes de tocar nada.
Command (m for help): p
3. Crear tabla MBR nueva (borra todo)alto riesgo
Para qué sirve: elimina cualquier partición previa y crea una etiqueta MBR limpia. Si prefieres conservar particiones existentes, usa d para borrarlas una por una en vez de esto.
Command (m for help): o
4. Crear partición /boot (1 GB)riesgo medio
Para qué sirve: reserva el espacio donde vivirá el kernel y el bootloader.
Command (m for help): n
Partition type: p  (primaria)
Partition number: 1
First sector: 2048  (Enter, valor por defecto)
Last sector: +1G
5. Crear partición swap (4 GB)riesgo medio
Para qué sirve: crea el espacio de intercambio y luego le asigna el tipo correcto (código 19 = Linux swap).
Command (m for help): n
Partition number: 2
First sector: (Enter)
Last sector: +4G

Command (m for help): t
Partition number: 2
Partition type: 19
6. Crear partición raíz (resto del disco)riesgo medio
Para qué sirve: usa todo el espacio restante para el sistema principal.
Command (m for help): n
Partition number: 3
First sector: (Enter)
Last sector: (Enter, usa el resto del disco)
7. Guardar cambios y saliralto riesgo
Para qué sirve: escribe la tabla de particiones al disco de forma definitiva. Antes de este paso, todo es reversible con q.
Command (m for help): w

Formatear las particiones

Un adelanto de lo que viene en el siguiente tramo del capítulo (creación de sistemas de archivos):

Formatear /boot y la raíz con XFSriesgo medio
Para qué sirve: prepara las particiones para poder guardar archivos. Borra cualquier dato existente en ellas.
mkfs.xfs -c options=/usr/share/xfsprogs/mkfs/lts_6.18.conf /dev/sda1
mkfs.xfs -c options=/usr/share/xfsprogs/mkfs/lts_6.18.conf /dev/sda3
Activar el swapbajo riesgo
Para qué sirve: inicializa la partición 2 como memoria de intercambio (se detalla en el capítulo siguiente).
mkswap /dev/sda2
swapon /dev/sda2

💡 ¿Por qué no lo necesitas en tu instalación?

Tu configuración usa GPT + UEFI (Capítulo 15), no MBR. Este capítulo existe como referencia por si en el futuro instalas Gentoo en hardware antiguo o en una VM que solo soporta BIOS legacy.
