Capítulo 21 — Instalando el archivo stage

Extraer el stage3 en tu partición raíz montada
¿Para qué sirve este paso? El stage3 es un paquete comprimido con un sistema Gentoo mínimo y funcional. Extraerlo en /mnt/gentoo es literalmente "sembrar" tu nuevo sistema operativo: todo lo que instales después se construye sobre esta base.

🧩 El comando principal

tar xpvf stage3-*.tar.xz --xattrs-include='*.*' --numeric-owner -C /mnt/gentoo
Riesgo medio — si falla o se interrumpe, se puede repetir sin problema (a diferencia de instalar el bootloader)
Ver qué hace cada bandera
BanderaQué hace
xExtract — extrae el contenido del archivo
pPreserva los permisos originales de cada archivo
vVerbose — muestra cada archivo mientras se extrae
fIndica que a continuación va el nombre del archivo
--xattrs-include='*.*'Conserva atributos extendidos (metadatos adicionales de algunos archivos)
--numeric-ownerMantiene los IDs numéricos de usuario/grupo tal cual, evitando líos de permisos
-C /mnt/gentooCambia de directorio antes de extraer, para que todo caiga en la partición raíz

💡 El truco del punto de montaje

/mnt/gentoo no es "un disco", es una puerta de entrada a tu partición real (por ejemplo /dev/sda3), gracias al mount que hiciste en el capítulo 18.

Cuando tar escribe con -C /mnt/gentoo, el kernel redirige esa escritura al disco físico montado ahí. Si no hubiera nada montado, todo se perdería al reiniciar, porque el entorno live vive en RAM.

✅ Verificación rápida

Después de extraer, puedes confirmar que el stage se desempaquetó correctamente:

ls /mnt/gentoo

Deberías ver carpetas como bin, etc, usr, var, etc. — la estructura típica de un sistema Linux.

Nota: El * en stage3-*.tar.xz es un comodín para no escribir el nombre completo (que incluye arquitectura, fecha e init system, ej. stage3-amd64-openrc-20240107T170309Z.tar.xz).
