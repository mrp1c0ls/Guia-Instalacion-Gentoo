Configurar los locales

Idioma, formato de fecha y codificación de caracteres del sistema

Un locale no es solo "el idioma". Es el conjunto de reglas que le dicen al sistema cómo mostrar mensajes, cómo ordenar texto alfabéticamente, cómo formatear fechas, horas, números y moneda. Este capítulo tiene dos pasos: generar los locales que quieres tener disponibles y luego elegir cuál usar por defecto.

Nota: este paso no aplica si el sistema usa la librería musl libc. Si no sabes qué es eso, este paso sí te aplica normalmente.

28.1 — Generación de locales

Gentoo trae disponible un archivo con más de 500 locales posibles, pero casi nadie los necesita todos. Por eso se genera solo una lista corta, definida en un archivo de configuración.

Editar la lista de locales Riesgo bajo 
root # nano /etc/locale.gen
Para qué sirve: abre el archivo donde declaras qué locales quieres tener disponibles en el sistema.

Dentro se escribe una línea por cada locale deseado, con el formato idioma_PAÍS.codificación:

/etc/locale.gen — ejemplo
en_US.UTF-8 UTF-8
es_MX.UTF-8 UTF-8
Para qué sirve: cada línea le dice al generador de locales cuáles compilar. Todo lo que no esté aquí, no se genera.
  • Los nombres son sensibles a mayúsculas y minúsculas: deben escribirse exactamente como aparecen listados.
  • La lista completa de locales soportados está en /usr/share/i18n/SUPPORTED.
  • Se recomienda tener al menos un locale en UTF-8: muchos programas lo requieren para compilar correctamente.
Generar los locales elegidos Riesgo bajo 
root # locale-gen
Para qué sirve: lee /etc/locale.gen y compila solo esos locales, ahorrando tiempo y espacio frente a generar los 500+ disponibles.
Verificar que quedaron disponibles Riesgo bajo 
root # locale -a
Para qué sirve: lista todos los locales ya generados en el sistema, para confirmar que el paso anterior funcionó.

28.2 — Selección de locale

Ya generados, hay que decirle al sistema cuál usar por defecto. Para esto se usa eselect, la herramienta genérica de Gentoo para gestionar configuraciones del sistema, con su módulo locale.

Ver los locales disponibles Riesgo bajo 
root # eselect locale list
Para qué sirve: muestra, numerados, todos los locales que ya fueron generados y pueden seleccionarse como el de la variable LANG.
¿Qué significa cada entrada de la lista?
EntradaSignificado
CLocale neutro/mínimo. Mensajes en inglés genérico, sin acentos, sin formato regional.
C.UTF-8Igual que C, pero soporta caracteres UTF-8 (acentos, ñ, símbolos).
POSIXAlias histórico de C, mismo comportamiento predecible.
de_DE.UTF-8Formato completo: idioma_PAÍS.codificación — aquí, alemán de Alemania en UTF-8.
es_MX.UTF-8Español de México en UTF-8 — el que aplica a esta instalación.
(free form)No es una opción numerada; permite escribir a mano un locale que no salió listado.
Seleccionar el locale a usar Riesgo bajo 
root # eselect locale set <NÚMERO>
Para qué sirve: fija el locale elegido como el valor de la variable LANG del sistema.
Recargar el entorno Riesgo bajo 
root # env-update && source /etc/profile && export PS1="(chroot) ${PS1}"
Para qué sirve: aplica el cambio de locale de inmediato en la sesión actual, sin esperar a un reinicio.
Alternativa manual (sin eselect)

También se puede fijar el locale editando directamente el archivo de entorno:

/etc/env.d/02locale
LANG="es_MX.UTF-8"
LC_COLLATE="C.UTF-8"

En sistemas con systemd, el archivo equivalente es /etc/locale.conf, y en vez de eselect se puede usar localectl set-locale o localectl list-locales.

Por qué importa este paso: configurar bien el locale evita advertencias y errores durante compilaciones de software más adelante en la instalación, y asegura que fechas, números y mensajes se muestren correctamente desde el primer arranque.

Resumen rápido

  1. Generar: editar /etc/locale.gen → correr locale-gen
  2. Seleccionar: eselect locale list → eselect locale set N
  3. Recargar: env-update && source /etc/profile
