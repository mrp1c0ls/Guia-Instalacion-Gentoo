Capítulo 19 — Eligiendo el Stage File

Compendio de instalación Gentoo · Sección: Base del sistema

En una frase: aquí decides el "molde" con el que va a nacer tu sistema Gentoo — qué sistema de init usará y si soportará software de 32 bits.

¿Qué es un Stage File?

Es un archivo comprimido que contiene un sistema Gentoo casi completo, ya preparado por el equipo de Gentoo. Lo vas a descomprimir dentro de tu partición raíz y a partir de ahí construyes todo lo demás. No es más que el punto de partida — no hay comandos en este capítulo, solo una decisión.

¿Por qué importa elegir bien? contexto

Porque cambiar de opción después de instalado es posible pero complicado, sobre todo pasar de "sin soporte 32 bits" a "con soporte 32 bits". Vale la pena decidir con calma ahora.

Eje 1: Sistema de init

El sistema de init es el proceso que arranca todos los servicios del sistema justo después de que carga el kernel.

OpciónQué esIdeal para
OpenRC Sistema de init nativo y original de Gentoo. Basado en dependencias entre servicios. Quien busca simplicidad y el enfoque tradicional de Gentoo
systemd Init moderno usado por la mayoría de distros Linux actuales (Ubuntu, Fedora, Arch, etc.) Quien ya conoce systemd de otras distros

Eje 2: Soporte de arquitectura

OpciónQué haceRiesgo
Multilib Usa librerías de 64 bits siempre que puede, y cae a 32 bits solo cuando algo lo necesita (ej. software o juegos viejos) recomendado
No-multilib Sistema 100% de 64 bits, sin ninguna librería de 32 bits avanzado
⚠️ Advertencia del manual: migrar de no-multilib a multilib después requiere conocimiento profundo de Gentoo y del toolchain de bajo nivel. Si eres principiante, evita no-multilib salvo que tengas una razón concreta para necesitarlo.

Tip que enriquece este capítulo: el flavor "desktop"

Además de init y multilib, algunos stage files incluyen la palabra desktop en el nombre. Estos vienen con paquetes como llvm y rust-bin preinstalados y ajustes de USE flags pensados para acelerar la instalación si vas a usar entorno gráfico. Si tu plan final incluye escritorio (GNOME, KDE, etc.), es útil tenerlo en mente aunque la elección real de perfil ocurre más adelante.

📖 ¿Cómo se relaciona esto con el perfil (profile) de Portage?

El stage file está basado en un perfil de Portage, pero no son lo mismo. El stage file es el punto de partida binario; el perfil (que seleccionas más adelante con eselect profile) define configuraciones por defecto como USE flags y versiones de paquetes permitidas. Elegir bien el stage ahora hace que el perfil correspondiente ya venga alineado, evitándote trabajo extra.
