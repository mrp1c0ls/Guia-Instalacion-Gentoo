Capítulo 2: Particionado del disco

Cómo dividir el disco antes de instalar Gentoo, y qué son UEFI, BIOS, GPT y MBR.

Conceptos base

MODERNO

UEFI / EFI

El firmware que enciende la máquina antes del sistema operativo. Busca un archivo de arranque dentro de una partición especial (ESP). Es el estándar actual.

LEGADO

BIOS

El firmware antiguo. No lee particiones ESP; arranca leyendo directamente el primer sector del disco (MBR). Común en equipos pre-2010.

MODERNO

GPT

Tabla de particiones moderna. Sin límite práctico de particiones, soporta discos enormes (>2 TiB). Se usa junto con UEFI.

LEGADO

MBR / DOS

Tabla de particiones antigua. Máximo 4 particiones primarias, límite de 2 TiB. Se usa junto con BIOS.

En resumen: UEFI+GPT es la pareja moderna recomendada. BIOS+MBR es la pareja legada, solo para hardware muy viejo o casos especiales (como algunas nubes tipo AWS).

Esquema de particiones recomendado (GPT + UEFI)

ParticiónPunto de montajeSistema de archivosPara qué sirve
/dev/sda1/efivfat (FAT)ESP: aquí el firmware UEFI encuentra el gestor de arranque
/dev/sda2—swapMemoria virtual: extiende la RAM usando disco
/dev/sda3/ext4 / xfs / etc.Raíz: contiene todo el sistema Gentoo instalado

Nota sobre BIOS boot partition

Solo se necesita si el disco usa GPT pero el equipo arranca en modo BIOS legado con GRUB2. No aplica si se usa UEFI puro (nuestro caso) ni con tabla MBR.

Comandos de fdisk

Se abre la herramienta apuntando al disco:

fdisk /dev/sda
Para qué sirve: entra al modo interactivo de fdisk para ver, crear o borrar particiones del disco indicado.
TeclaAcción
pVer la tabla de particiones actual
gCrear tabla nueva tipo GPT (borra lo existente)
oCrear tabla nueva tipo MBR/DOS (borra lo existente)
nCrear una partición nueva
dBorrar una partición
tCambiar el tipo de una partición
aMarcar como booteable (solo en MBR)
wGuardar los cambios en el disco
qSalir sin guardar nada
Ver ejemplo completo paso a paso 
fdisk /dev/sda

n → 1 → Enter → +1G      # partición 1: ESP (arranque)
t → 1                    # tipo: EFI System

n → 2 → Enter → +4G      # partición 2: swap
t → 2 → 19                # tipo: Linux swap

n → 3 → Enter → Enter    # partición 3: root, usa el resto del disco
t → 3 → 23                # tipo: Linux root (x86-64), opcional

w                          # guardar y salir
Riesgo: medio — hasta presionar w nada se escribe en el disco; se puede salir con q sin dañar nada.
En una frase:

Se divide el disco en 3 partes — una pequeña para el arranque (ESP), una para memoria virtual (swap), y una grande para el sistema (root) — usando fdisk con tabla GPT porque el equipo usa UEFI.
