Capítulo 10 — Configuración específica de aplicaciones

La "caja de herramientas" de red para cuando nmtui no basta: proxies web, ADSL por PPPoE y VPN por PPTP. Solo aplica si tu conexión no funciona con DHCP normal.

Capítulo original: 10 — Application specific configuration Subsecciones: 10.1 – 10.3
¿Cuándo leer este capítulo? Solo si tu red no se conectó sola al arrancar el medio de instalación. Si ya tienes internet (por ejemplo, con nmtui o por cable con DHCP), puedes saltarte todo este capítulo.

10.1 · Proxies web

Un proxy es un intermediario entre tu equipo e internet — común en redes de oficinas, universidades o instituciones. Si tu salida a internet pasa por uno, Portage (el gestor de paquetes) no sabrá llegar a los servidores de descarga a menos que se lo indiques.

Para qué sirve Definir variables de entorno le dice a Portage y a otras herramientas de descarga (como el navegador de texto links) por dónde deben salir a internet.
VariableProtocolo que cubreQuién la usa
http_proxyHTTPPortage y links
https_proxyHTTPSSolo links
ftp_proxyFTPPortage y links
RSYNC_PROXYrsync (sincronía del árbol de Portage)Solo Portage
root # export http_proxy="http://proxy.gentoo.org:8080"
root # export https_proxy="http://proxy.gentoo.org:8080"
root # export ftp_proxy="ftp://proxy.gentoo.org:8080"
root # export RSYNC_PROXY="proxy.gentoo.org:8080"
Si el proxy pide usuario y contraseña

Se incrustan directamente en la URL, antes del host:

root # export http_proxy="http://usuario:contraseña@proxy.gentoo.org:8080"

Riesgo medio La contraseña queda visible en el historial de la terminal y en la lista de procesos mientras la variable está definida. Solo hazlo en un entorno que confíes (como el medio de instalación, que es temporal).

Dato clave Estas variables solo existen mientras dura la sesión de la terminal — se pierden si reinicias o cierras la ventana. No es un ajuste permanente todavía; eso se configura más adelante, ya con el sistema instalado.

10.2 · ADSL con PPPoE

Si tu proveedor de internet usa ADSL y requiere autenticarte con usuario/contraseña sobre Ethernet (protocolo PPPoE), el medio de instalación incluye un script guiado que hace casi todo el trabajo.

Para qué sirve pppoe-setup genera automáticamente la configuración necesaria en /etc/ppp/ para que tu conexión ADSL funcione, sin tener que editar archivos a mano. 
root # pppoe-setup
root # pppoe-start

Durante el asistente te preguntará por:

  • La interfaz Ethernet conectada al módem
  • Usuario y contraseña del PPPoE
  • IPs de servidores DNS
  • Si quieres activar un firewall básico
Si la conexión falla
  • Revisa que las credenciales sean correctas en /etc/ppp/pap-secrets o /etc/ppp/chap-secrets.
  • Confirma que elegiste la interfaz Ethernet correcta (la que está físicamente conectada al módem).

10.3 · VPN con PPTP

PPTP es un protocolo de VPN más antiguo. Si tu proveedor o tu red exige conectarte por PPTP para tener salida a internet, se usa el paquete pptpclient.

Para qué sirve Establece un túnel cifrado hacia un servidor remoto; tu tráfico de red pasa por ese túnel en vez de salir directo.

Configuración en tres pasos:

root # nano /etc/ppp/chap-secrets   # usuario y contraseña
root # nano /etc/ppp/options.pptp   # opciones adicionales, si aplica
root # pptp <IP del servidor>
Nota de seguridad Riesgo medio PPTP es un protocolo considerado inseguro para hoy en día (tiene vulnerabilidades conocidas de cifrado). Es útil como salida rápida de emergencia durante la instalación, pero no se recomienda como VPN permanente en producción — para eso existen alternativas modernas como WireGuard u OpenVPN.
