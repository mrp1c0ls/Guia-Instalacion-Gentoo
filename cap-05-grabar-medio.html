Idea general

Ya tienes el archivo .iso de Gentoo descargado, pero un ISO por sí solo no arranca una computadora. Este capítulo explica cómo "volcar" ese ISO a un USB o disco físico para que la máquina pueda iniciar desde ahí.

5.1 Crear un USB booteable

Advertencia: No uses herramientas como Ventoy para escribir el USB — puede provocar fallos de arranque con el medio de Gentoo.
Paso 1 — Identificar el dispositivo USB riesgo bajo

Antes de escribir nada, hay que saber qué nombre tiene tu USB en el sistema (ej. /dev/sdd).

root # dmesg
root # lsblk
Para qué sirve: dmesg muestra el hardware detectado recientemente (útil justo después de conectar el USB). lsblk lista todos los discos y particiones del sistema para confirmar cuál es el correcto por su tamaño.
Paso 2 — Escribir el ISO con dd riesgo alto 
root # dd if=install-amd64-minimal-<fecha>.iso of=/dev/sdd bs=4096 status=progress && sync
ParteSignificado
if=archivo de entrada (el ISO descargado)
of=dispositivo de salida (tu USB) — todo su contenido se borra
bs=4096tamaño de bloque, acelera la escritura
status=progressmuestra el avance en tiempo real
syncfuerza a que todo quede realmente escrito antes de retirar el USB
Cuidado: usa el dispositivo base (sdd), no una partición (sdd1). Si te equivocas de of=, borras el disco incorrecto — no hay "deshacer".
Para qué sirve: dd copia el ISO byte por byte al USB, replicando la estructura de arranque (particiones GPT incluidas) tal cual la trae la imagen oficial.
Alternativa en Windows riesgo bajo

Se usa el programa gráfico win32diskimager, que cumple la misma función que dd pero con interfaz visual.

Advertencia del manual: descárgalo únicamente desde su página oficial en SourceForge, para evitar versiones alteradas.

5.2 Grabar en disco (CD/DVD)

En Linux — cdrecord riesgo medio 
user $ cdrecord dev=/dev/sr0 install-amd64-minimal-20141204.iso
Para qué sirve: graba el ISO como imagen booteable en un disco físico. /dev/sr0 es la primera unidad óptica del sistema.

Si prefieres interfaz gráfica, K3B hace lo mismo desde su menú "Grabar imagen de CD".

En Windows 7 o superior riesgo bajo

No necesitas programas extra: clic derecho sobre el archivo ISO → "Grabar imagen de disco".

Extra: comparación rápida de métodos

Tip (aporte adicional): antes de grabar, verifica la integridad del ISO comparando su checksum (sha256sum install-amd64-minimal-<fecha>.iso) contra el valor publicado en la página de descargas de Gentoo. Un ISO corrupto puede causar errores extraños durante la instalación que son difíciles de diagnosticar después.
Tip (aporte adicional): el USB es preferible al CD/DVD hoy en día — es más rápido, reutilizable, y casi todo hardware moderno arranca desde USB sin problema.
