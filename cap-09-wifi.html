📶 Configuración Inalámbrica (WiFi)

Cómo conectar tu equipo a una red WiFi desde el medio de instalación

Si tu máquina se conecta a internet por cable Ethernet, este capítulo no aplica: el DHCP ya resolvió la conexión automáticamente. Este capítulo es solo para cuando dependes de WiFi para instalar Gentoo. Existen tres formas de lograrlo, de la más simple a la más manual.

🖱️ NetworkManager Fácil

Menú interactivo. Recomendado para casi todos los casos.

⚙️ net-setup Alternativa

Asistente por preguntas. Se usa cuando no hay NetworkManager.

🔧 Manual Avanzado

Control total con wpa_supplicant / iwd. Para redes abiertas o casos especiales.

0 Antes de empezar: comprobar la tarjeta (opcional)

Sin riesgo

Verifica que el kernel detecta tu tarjeta inalámbrica antes de configurar nada.

root # iw dev wlp9s0 info
Para qué sirve: confirma que el driver del WiFi está cargado. Si el nombre de tu interfaz no es wlp9s0 (puede ser wlan0 o ra0), revisa el nombre correcto con ip link.

1 Opción A — NetworkManager (recomendada)

Sin riesgo

Paso único: ejecuta el asistente de texto y sigue el menú.

root # nmtui
Para qué sirve: abre una interfaz de menús donde eliges tu red y escribes la contraseña, sin comandos adicionales. Si usas la LiveGUI (versión con escritorio), basta con hacer clic en el ícono de red de la barra de tareas.

2 Opción B — net-setup

Úsala solo si NetworkManager no está disponible en tu medio de instalación.

Sin riesgo

Paso 1: detener el cliente DHCP activo para evitar conflictos.

root # killall dhcpcd
Para qué sirve: libera la interfaz de red para que net-setup pueda configurarla sin interferencias.
Sin riesgo

Paso 2: lanzar el asistente sobre tu interfaz.

root # net-setup enp1s0
Para qué sirve: hace preguntas paso a paso (nombre de red, contraseña) y configura automáticamente wpa_supplicant o una IP fija según tus respuestas.

3 Opción C — Configuración manual

Para usuarios avanzados o redes abiertas sin contraseña.

Sin riesgo

Paso 1: activar la interfaz inalámbrica.

root # ip link set dev wlp9s0 up
Para qué sirve: "enciende" la tarjeta a nivel de kernel; sin esto no puede detectar ni asociarse a ninguna red.
Sin riesgo

Paso 2: para redes con contraseña (la mayoría), usar un daemon como wpa_supplicant o iwd para autenticarte. Para redes abiertas, con activar la interfaz suele bastar para asociarte al ESSID.

Para qué sirve: estos programas manejan el protocolo de seguridad WiFi (WPA2/WPA3). El handbook los explica a fondo en el capítulo de "Redes inalámbricas" aparte.

✨ Para enriquecer: cosas útiles que no siempre se mencionan

  • Verifica siempre después de conectar. Haz ping gentoo.org (o cualquier dominio) para confirmar que hay internet real, no solo asociación WiFi.
  • El nombre de la interfaz cambia entre equipos. Gracias al esquema de nombres predecibles de systemd, puede ser wlp2s0, wlp3s0, etc. — nunca asumas que será igual al de otra máquina.
  • Esta configuración es temporal. Todo lo hecho aquí es solo para el medio de instalación (LiveCD/USB). Una vez dentro del sistema instalado, deberás configurar la red de nuevo con netifrc u otra herramienta permanente (ya cubierto en tu instalación).
  • Si algo falla, el propio handbook recomienda volver a la configuración manual de red como respaldo — es la opción con más control cuando los asistentes no detectan bien el hardware.
